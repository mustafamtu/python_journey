# Python Journey

Bu depo, sıfırdan başlayıp ileri seviye yazılım mimarilerine, nesne yönelimli programlamaya ve uygulamalı yapay zekâ mühendisliğinin temelini oluşturan modern Python pratiklerine uzanan kişisel öğrenme ve kodlama sürecimi içermektedir.

Tüm içerikler modüler klasör yapısında, temiz kod prensipleri ve uygulamalı scriptler üzerinden yapılandırılmıştır.

---

## Müfredat 

| # | Konu / Modül | Odak & Kapsam |
|---|---|---|
| **01** | `01_Temeller_ve_VeriTipleri` | Değişkenler, tip dönüşümleri, bellek yönetimi temelleri |
| **02** | `02_Listeler_ve_Koleksiyonlar` | Listeler, tuple, dictionary, set operasyonları ve metodları |
| **03** | `03_Operatorler` | Aritmetik, mantıksal, atama ve üyelik operatörleri |

| **05** | `05-Döngüler` | `for`, `while`, `break`, `continue`, `enumerate`, `zip` |
| **06** | `06-Fonksiyonlar` | Fonksiyon tanımlama, `*args`, `**kwargs`, scope (kapsam) |

| **10** | `10-Moduller` | Yerel ve harici paket yönetimi, `pip`, import mekanizmaları |
